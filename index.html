HOW TO PLAY English
Android
PowerTunnel Method
  1. Download PowerTunnel for Android.
  2. Open PowerTunnel and enable the VPN service.
  3. Copy the PowerTunnel URL from the Host & Download section.
  4. Use the copied URL in PowerTunnel.
  5. Open Growtopia and connect to the server.
💻
Windows / PC
Hosts File Method
  1. Click Download Host.
  2. Open the downloaded host.txt file.
  3. Copy the contents into your system hosts file.
  4. Save the hosts file.
  5. Restart Growtopia.
📱
iOS
iOS Host Method
  1. Press the iOS Host button.
  2. Follow the instructions provided by the server.
  3. Install the required configuration.
  4. Open Growtopia.
  5. Connect to the private server.
🎮
General
Need Help?
  1. Make sure the server status says ONLINE.
  2. Make sure your host configuration is correct.
  3. Restart Growtopia if the connection does not work.
  4. Join our Discord server if you need assistance.
